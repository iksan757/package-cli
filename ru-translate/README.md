# ru-translate 

Easy and fast CLI Translation tool supporting auto-language detection. Works smoothly on Linux, macOS, Windows, and **Termux** (Android).
---
## 📥 Installation

```bash
npm install -g ru-translate
```
---
## Usage

# Translate simple text (default target: English)
- rutrans "Selamat pagi" en

# Translate to specific language (e.g., Japanese)
- rutrans "Terima kasih" ja

# Translate contents of a file
- rutrans -f ./document.txt es

# Interactive mode
- rutrans -i

# Show supported languages
- rutrans -l

# Show help menu
- rutrans -h
