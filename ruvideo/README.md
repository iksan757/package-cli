# RUVIDEO V19.2.0

Fast and simple video downloader tool written in Rust forfetching media links directly from the CLI
---
## EXAMPLE 
- Create rename
```
ruvideo "URL" -o example.mp4
```
_ Create new directory
```
ruvideo "URL" -d path/path/
```
- Combine 
```
ruvideo "URL" -o example.mp4 -d path/path/
```
- Use dns 1.1.1.1
```
ruvideo "URL" -o example.mp4 -d path/path/ --dns 1.1.1.1
```
-  more information
```
ruvideo --help
``'
---

## NOTE

Take the link from the video streaming website, wait until play and copy the link in your
browser bar
